# 1. injectivity and surjectivity
## 1.1 Problem1's Statement

> [!abstract] **Theorem (Finite Set Mapping Property)**
> 
> Let $A$ and $B$ be finite sets with $\vert{}A\vert{} = \vert{}B\vert{} = n \in \mathbb{N}$.
> 
> If a map $T: A \to B$ is **surjective**, then $T$ is also **injective** (and hence bijective).
> 
>   

## 1.2 Preliminary Definitions & Core Properties

### 1.2.1 Cardinality of Finite Sets

> [!note] **Definition: Cardinality**
> 
> For a finite set $A$, if there exists a **bijection** $f: A \to I_k$, where $I_k = \{1, 2, \dots, k\} \subset \mathbb{N}$ is an initial segment of the natural numbers, then the unique natural number $k$ is defined as the **cardinality** of $A$, denoted by $\vert{}A\vert{} = k$.
> 
>   

### 1.2.2 Cardinality and Mappings

For any mapping $f: X \to Y$ between finite sets:

- **Surjectivity**: If $f$ is surjective, then $f(X) = Y$, which implies **$\vert{}X\vert{} \ge \vert{}Y\vert{}$**.
- **Injectivity**: If $f$ is injective, then $X$ is in one-to-one correspondence with the image $f(X) \subseteq Y$, which implies **$\vert{}X\vert{} \le \vert{}Y\vert{}$**.

## 1.3 Proof

### Proof by Contradiction

1. **Assume the contrary**:
    Suppose $T: A \to B$ is surjective, but $T$ is **not** injective.
    
2. **Deduce size reduction of the image**:  
    - Since $T$ is not injective, there exist two distinct elements $a_1, a_2 \in A$ ($a_1 \neq a_2$) such that $T(a_1) = T(a_2) = b^* \in B$.
    - Consider the proper subset $A' = A \setminus \{a_2\}$. Its cardinality is $\vert{}A'\vert{} = \vert{}A\vert{} - 1 = n - 1$.
    - Removing $a_2$ does not change the coverage of the image because $T(a_1) = b^*$, so:
$$T(A) = T(A')$$
3. **Bound the image size**:
    - The size of the image $T(A)$ cannot exceed the size of the domain $A'$:$$\vert{}T(A)\vert{} = \vert{}T(A')\vert{} \le \vert{}A'\vert{} = n - 1$$
4. **Derive a contradiction**:
    - By surjectivity, $T(A) = B$, which means $\vert{}T(A)\vert{} = \vert{}B\vert{} = n$.
    - Combining these yields the inequality:
$$n = \vert{}T(A)\vert{} \le n - 1$$
    - This is a contradiction ($n \le n - 1$).
        
5. **Conclusion**:
    The assumption must be false. Therefore, $T$ must be injective.

## 1.4 Counter-example for Infinite Sets

> [!warning] **Caveat: Failure in Infinite Sets**
> 
> For infinite sets, a proper subset can have the same cardinality as the whole set (a defining characteristic of Dedekind-infinite sets). Thus, surjectivity does not guarantee injectivity.
> 
>   

### Counter-example Construction

Let $A  = \{0, 1, 2, 3, \dots\}$, so both sets have the same infinite cardinality.

Define $T: A \to A$ using the floor function:
$$T(x) = \left\lfloor \frac{x}{2} \right\rfloor$$
1. **Verify Surjectivity**:
    For any $k \in A$, choose $x = 2k \in A$. Then $T(2k) = \lfloor 2k / 2 \rfloor = k$.
    Thus $T(A) = A$, meaning $T$ is surjective.
    
2. **Verify Non-Injectivity**:
    Choose $x_1 = 0$ and $x_2 = 1$, where $x_1 \neq x_2$.
    We have $T(0) = 0$ and $T(1) = \lfloor 0.5 \rfloor = 0$, so $T(0) = T(1)$.
    Therefore, $T$ is not injective.

**Conclusion**: For infinite sets, $\vert{}A\vert{} = \vert{}A\vert{}$ and surjectivity of $T: A \to A$ do not guarantee that $T$ is injective.

# 2. Cardinality of sets
## 2.1 Cardinality's Alternative Definition

> [!note] **Definition: Minimized Bounds via Subsets of Natural Numbers**
> 
> Let $A$ be a non-empty finite set. Consider the collection $\mathcal{S}$ of all non-empty finite subsets $S \subset \mathbb{N}$ such that there exists a bijection $f: A \to S$:
> 
>   
> 
> $$\mathcal{S} = \{ S \subset \mathbb{N} \mid \exists f: A \to S, f \text{ bijects} \}$$
> 
> For each subset $S \in \mathcal{S}$, define its maximum element as $\max(S)$. The **cardinality** of $A$, denoted $\vert{}A\vert{}$, is defined as the minimum of these maximum elements across all valid subsets $S$:
> 
>   
> 
> $$\vert{}A\vert{} := \min_{S \in \mathcal{S}} \Big( \max(S) \Big)$$
> 
> _(For the empty set, we define $\vert{}\emptyset\vert{} = 0$.)_
> 
>   

### 2.2 Equivalence to the Standard Definition

To see why this definition works, consider $n = \vert{}A\vert{}$ under the standard definition(where $A$ maps bijectively to $I_n = \{1, 2, \dots, n\}$). Since empty set case is trivial, we assume $n\ge1$ :

1. **Existence of Upper Bound**: The standard initial segment $I_n = \{1, 2, \dots, n\}$ is itself a valid subset in $\mathcal{S}$. Its maximum element is $\max(I_n) = n$. Thus, the minimum cannot exceed $n$:
$$\min_{S \in \mathcal{S}} \Big( \max(S) \Big) \le n$$

2. **Lower Bound Constraint**: Any subset $S \subset \mathbb{N}$ that can be placed in bijection with $A$ must contain exactly $n$ distinct elements. Any subset of $\mathbb{N}$ containing $n$ distinct positive integers must have a maximum element at least as large as $n$ (achieved only when $S = \{1, 2, \dots, n\}$). Thus:
$$\max(S) \ge n \quad \forall S \in \mathcal{S}$$
   Taking the minimum over all $S \in \mathcal{S}$ yields exactly $n$.

### 2.3 Examples

#### Example 1: A Three-Element Set

Let $A = \{\text{apple}, \text{banana}, \text{cherry}\}$.

- **Choice 1**: Map $A$ to $S_1 = \{1, 2, 3\}$ via $f_1$.
$$\max(S_1) = 3$$

- **Choice 2**: Map $A$ to $S_2 = \{5, 100, 200\}$ via $f_2$.
$$\max(S_2) = 200$$

- **Choice 3**: Map $A$ to $S_3 = \{2, 4, 6\}$ via $f_3$.
$$\max(S_3) = 6$$

Across all possible finite subsets $S \subset \mathbb{N}$ that can be placed in bijection with $A$, the smallest possible value for $\max(S)$ occurs when we pack the numbers as tightly as possible starting from $1$, which gives $S = \{1, 2, 3\}$.

$$\min_{S \in \mathcal{S}} \Big( \max(S) \Big) = \min(3, 200, 6, \dots) = 3 \implies \vert{}A\vert{} = 3$$

#### Example 2: The Single Element Set

Let $A = \{x\}$.

- Example of valid target subsets may include $\{1\}, \{2\}, \{3\},...$

- The maximum elements for these subsets are $1, 2, 3$, respectively.

- The minimum over all valid maximums is $\min\{1, 2, 3, \dots\} = 1$.

thus, $\vert{}A\vert{} = 1$
