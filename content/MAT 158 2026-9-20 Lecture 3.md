>[!note] Last Theorem on sets 
>These following three statements are equivalent:
>1. There exists an injection $S:\mathbb{Z}^+\to A$
>2. $A$ is infinite
>3. There exists a bijection $T:A\to A_1, \,\,A_1\subsetneq A$

>[!note] Prove of $1\iff 2$
>we are going to prove $1\Rightarrow 2$ by prove by contradiction
>suppose that $A$ is finite, then $A$ can be listed as follows:
>$\exists n\in \mathbb{Z}^+,\,\,A=\{a_1,a_2,a_3,...,a_n\}$
>however, this would trivially bring us a contradiction. Since $|A|=n<|\mathbb{Z}^+|$, there is not injection $S:\mathbb{Z}^+\to A$
>Thus, $1\Rightarrow 2$
>
>now, let us prove $2 \Rightarrow 1$
>To prove $2\Rightarrow 1$, we first need to prove that given a collection $\mathcal{B}$ of nonempty sets (not necessarily disjoint), there exists a function
$$c: \mathcal{B} \to \bigcup_{B \in \mathcal{B}} B$$
such that $c(B) \in B$ for each $B \in \mathcal{B}$. The function $c$ is called a **choice function** for the collection $\mathcal{B}$.
>
>For each $B \in \mathcal{B}$, define a set $B'$ as follows:
>$$B' = \{(B, x) \mid x \in B\}$$
>That is, $B'$ is the collection of all ordered pairs where the first coordinate is the set $B$, and the second coordinate is an element of $B$. Since $B$ is nonempty, $B'$ is nonempty.
>Now consider the collection $\mathcal{C} = \{B' \mid B \in \mathcal{B}\}$. If $B_1$ and $B_2$ are two different sets in $\mathcal{B}$, then the corresponding sets $B_1'$ and $B_2'$ are disjoint. A typical element of $B_1'$ is of the form $(B_1, x_1)$ and a typical element of $B_2'$ is of the form $(B_2, x_2)$. No two such elements can be equal because their first coordinates are different. Thus, $\mathcal{C}$ is a collection of disjoint nonempty sets.
>
>By the Axiom of Choice, there exists a set $c$ consisting of exactly one element from each set $B' \in \mathcal{C}$. Therefore, for each $B \in \mathcal{B}$, the set $c$ contains exactly one ordered pair $(B, x)$ whose first coordinate is $B$. Considering the definition of a function as the set of ordered pairs, this would allow us defining $c(B) = x$. Since $(B, x) \in c$ implies $x \in B$, we have $c(B) \in B$
>
>Now, assume $A$ is an infinite set. We wish to construct an injection $S: \mathbb{Z}^+ \to A$. Let $\mathcal{B}$ be the collection of all nonempty subsets of $A$.
>By Lemma 9.2, there exists a choice function $c: \mathcal{B} \to A$ such that $c(B) \in B$ for each $B \in \mathcal{B}$.
>define function $S: \mathbb{Z}^+ \to A$:
>- $S(1) = c(A)$
> - $S(i) = c(A \setminus \{S(1), S(2), \dots, S(i-1)\}),i > 1$
>Therefore, there exists an injection $S: \mathbb{Z}^+ \to A$. Thus, $2 \Rightarrow 1$
>
>Therefore, $2 \iff 1$


>[!note] Prove of $1\iff 3$
>first, let us prove $1\Rightarrow 3$
>given that we have an injection $S:\mathbb{Z}^+\to A$, and that range of $S$ is a subset(**not nessesarily a proper subset**) of codomain of $S$, we could extract the range from codomain, obtaining $A_2\subset A,\,\,A_2=\{a_1,a_2,...\}$ where $a_j=S(j)$
>Therefore, we now have an infinite, ordered array. We could now construct the proper subset of $A$ by $T:A\to A\setminus\{a_1\}$ 
>$$T(a)=\begin{cases}a_{j+1}, & a=a_j \in A_2,\\[4pt]a, & a\notin A_2.\end{cases}​$$ 
>And this is trivially a bijection
>
>Then, let us prove $3 \Rightarrow 1$
>given that there is a bijection $T:A\to A_1, \,\,A_1\subsetneq A$, we could see there must exists an element $a\in A,\,\,a\notin A_1$
>Focusing on this, construct an array by operating $T$ infinite times
>$$T(a),T^2(a),T^3(A),...$$
>Now, we would like to prove that non of these elements are the same.
>Suppose $\exists b,c\in \mathbb{Z}^+, b\neq c, T^b(a)=T^c(a)$
>Since $T$ is bijective, it must be injective, thus cancellation law works. 
>Therefore, $a=T^{c-b}(a)$, but this is impossible, as $T^{c-b}(a)\in A_1, \,\,a\notin A_1$
>Thus, trivially, we define $S:\mathbb{Z}^+\to A$, 
>$$\forall n\in \mathbb{Z}^+, \,\, S(n)=T^{n}(a)$$
>and this is an injection for sure
>Now, $S$ is well-defined, we have rigorously constructed .
>Therefore, $3\Rightarrow 1$

>[!abstract] Conclusion
>Since $1\iff 3$, $1\iff 2$, we obtained the final result:
>$$1\iff 2 \iff 3$$
